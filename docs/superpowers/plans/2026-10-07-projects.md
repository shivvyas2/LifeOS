# Projects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Projects tab (hard-edged, coloured) where people create projects, plan tasks on a board, a schedule, milestones and a list, share projects with friends, and see their assigned tasks on Today.

**Architecture:** Tested rules and models in `Persistence` (`ProjectProgress`, `BoardMove`, `ScheduleLayout`, `ContributionScale`, `ProjectMerge`, the SwiftData records and `ProjectsStore`); `ProjectSync` in `Integrations` on the `NoteSync` pattern over `SupabaseREST`; `ProjectColour` and `BrutalCard` in `DesignSystem`; one migration with RLS through `is_project_member`; the app's tab, screens and Today hooks.

**Tech Stack:** SwiftData, SwiftUI, Swift Testing, Postgres RLS, pgTAP (written, run where Docker is available), GitHub GraphQL for contributions, XCUITest.

**Spec:** `docs/superpowers/specs/2026-10-07-projects-design.md`

## Global Constraints

- Statuses `todo`, `doing`, `done`; roles `owner`, `member`; colours `tomato`, `marigold`, `moss`, `lagoon`, `iris`, `rose`.
- Limits: name 1–60, scope ≤ 240, milestone title 1–80, task title 1–120, notes ≤ 2000.
- Cursor key `projects.sync.cursor`, rewound one second on pull; newest `updated_at` wins; tombstones via `deleted_at`.
- Copy: `PROJECTS`, `+ NEW`, `+ TASK`, `+ MILESTONE`, `CONTRIBUTIONS`, `<n> THIS YEAR`, `TODAY'S TASKS`, `BOARD · SCHEDULE · MILESTONES · LIST`, `TO DO`, `DOING`, `DONE`, `ARCHIVED (n)`, `Members`, `Link repo`, `Unlink repo`, `Edit project`, `Archive`, `Leave project`, `Delete task`.
- The brutal look is confined to the Projects tab and the Today `projects` module; fonts from `LifeOSType` only; `scripts/check-typography.sh` reports nothing new.
- `LifeOSKit` builds for macOS. New SwiftData models are added to `LifeOSContainer.schema`, every stored property optional or defaulted (installed stores must open).
- Commits conventional, no em dashes, no attribution. Worktree `.claude/worktrees/projects` on `feat/projects` from main e40d81b. Simulator `B192EA65-BAA2-4814-A298-94A2F0C8FC87`; DerivedData `~/Library/Developer/Xcode/DerivedData/projects`.

## Review Focus

1. Moving a task into `done` and back must stamp and clear `done_at`, and renumber both columns without gaps: `BoardMoveTests.doneStampsAndLeavingClears`.
2. A local edit made while offline and newer than the server's row must survive the next pull: `ProjectMergeTests.aNewerLocalEditSurvives`.
3. Two overlapping time blocks must sit side by side, a third that overlaps only one must reuse the free lane: `ScheduleLayoutTests.overlapsShareLanes`.
4. A project with no tasks shows 0%, never NaN: `ProjectProgressTests.emptyIsZero`.
5. A non-member must read nothing and a member must not change membership: the pgTAP file in Task 3 (run where Docker is available; read in review otherwise).

### Task 1: The rules

**Files:** Create `LifeOSKit/Sources/Persistence/ProjectRules.swift`, `LifeOSKit/Tests/PersistenceTests/ProjectRulesTests.swift`.

**Produces:** `ProjectStatus: String, CaseIterable, Codable { todo, doing, done }`; `struct ProjectProgress { static func of(_ statuses: [ProjectStatus]) -> (done: Int, total: Int, fraction: Double) }`; `struct BoardCard: Equatable { id: UUID; status: ProjectStatus; position: Int; doneAt: Date? }`; `enum BoardMove { static func move(_ id: UUID, to status: ProjectStatus, at index: Int, in cards: [BoardCard], now: Date) -> [BoardCard] }` (returns every changed card, columns renumbered 0…n−1); `struct TimeBlock: Equatable { id: UUID; start: Date; end: Date }`; `enum ScheduleLayout { static func lanes(_ blocks: [TimeBlock]) -> [UUID: (lane: Int, lanes: Int)] }`; `enum ContributionScale { static func levels(_ counts: [Int]) -> [Int] }` (0 for zero, 1–4 by quartiles of non-zero counts); `enum ProjectMerge { static func keepLocal(localUpdatedAt: Date, localSyncedAt: Date?, remoteUpdatedAt: Date) -> Bool }` (true when the local row has an unsynced edit newer than the remote).

- [ ] **Tests first** (`ProjectRulesTests.swift`): `ProjectProgressTests.emptyIsZero` (0/0 → fraction 0), `counts` (2 done of 5 → 0.4); `BoardMoveTests.withinAColumn`, `acrossColumnsRenumbersBoth`, `doneStampsAndLeavingClears`; `ScheduleLayoutTests.alone`, `overlapsShareLanes` (A 9–11, B 10–12, C 11:30–12:30 → A lane 0, B lane 1, C lane 0, all `lanes` 2 within the overlapping group); `ContributionScaleTests.levels` ([0,1,2,3,4,8] → [0,1,1,2,3,4] by quartiles of [1,2,3,4,8]); `ProjectMergeTests.aNewerLocalEditSurvives`, `aSyncedLocalLoses`.
